# Notes App

A simple notes app built with plain HTML, CSS and JavaScript. No install or build step.

## Features
- Create a note with a title and text
- View all saved notes (newest first, with date and count)
- Edit any saved note in place (Save changes or Cancel)
- Delete any note
- Notes persist in the browser via localStorage
- Light and dark mode follow your system setting

## Run
Unzip the folder and open `index.html` in any modern browser.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - create, list, delete and storage logic

## Note
Notes are stored in your browser only, so they are not shared across devices or browsers.
